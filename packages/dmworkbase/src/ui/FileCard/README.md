# FileCard

共享的纯展示文件卡，供聊天编辑器的附件和文件消息使用。不读取 SDK、上传任务或网盘权限；调用方传入操作和上传状态。

- 固定 280 × 84，图标 40 × 40，名称区 184 × 40（两行，每行 20）。
- 名称按字符换行，两行省略；短名称预留第二行，元信息位置不变。
- `onRemove` 显示右上角移除按钮，调用方提供本地化 `removeLabel`。
- `actions` 放置已发送卡的网盘、下载或失败重试按钮。
- `progress`（包括 0）显示进度条并隐藏元信息和操作；调用方收到上传成功后移除该属性。100% 本身不表示上传成功。
- 文件名后缀优先于 `extension`，沿用共享文件类型图标；`icon` 可传入图片/视频缩略图。

Storybook：`pnpm --dir apps/web storybook --ci`，打开 `Base/FileCard`，切换 light/dark。`AllVariants` 比较长短名称和三种状态；`English` 检查英文；`States` 演示进度到 100% 后切换。

业务回归：在聊天窗口选择两个文件（包含一个小于 1 MB 的文件），移除其中一个并发送；确认首次显示 0%、上传期间没有下载/网盘按钮、上传成功后出现正式卡，预览/下载/转存沿用原操作。网盘按钮仍遵守原有功能开关、频道支持和消息确认条件。
