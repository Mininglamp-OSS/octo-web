# Chat layout coverage CH21–CH26

## Metadata

- Case 类型: UI flow
- 目标模式: real-page seed
- 优先级: P1
- Tags: `@CH21 @CH22 @CH23 @CH24 @CH25 @CH26 @CH28 @CH32 @CH34 @p1 @chat`
- Scope: Chat 页面左右布局的可观察入口、列表状态和右侧面板
- Implementation: `apps/web/e2e-kit/tests/chat/chat-layout-coverage.spec.ts`

## 目标

验证 Chat 左侧导航/列表与右侧详情面板的主要入口能够打开，并展示对应的用户可见状态。

## 前置条件

- 用户已登录并进入 Chat。
- 使用 case-specific mock 提供会话、关注列表、搜索空结果和 Summary 数据。

## 用户操作步骤

1. 在左侧顶部打开全局搜索和添加菜单。
2. 切换关注 Tab，观察关注视图。
3. 打开群会话，分别打开群设置、子区、会话内搜索和 Summary。

## 预期结果

- 全局搜索 dialog、添加菜单、群设置、子区列表、会话搜索结果和 Summary 面板均可见。
- 搜索无命中时显示「暂无匹配结果」。

## 反例

- 点击入口后面板未打开。
- 关注 Tab 退化为最近会话视图。
- 搜索空结果未显示，或 Summary/子区/群设置面板不可见。

## Cases

### CH21 — 左侧顶部搜索与添加

打开 Chat，点击顶部搜索和添加图标；分别看到全局搜索 dialog 与添加菜单。

### CH22 — 关注 Tab

切换到关注 Tab；看到关注视图的整理/分组空态入口，且关注数据接口由 case handler 提供。

### CH23 — 会话详情顶部群设置

打开群会话，确认详情 header 标题，再点击右侧群设置入口，右侧设置面板打开。

### CH24 — 子区列表

打开群会话，点击详情 header 子区入口，右侧子区列表面板打开并显示子区区域标题。

### CH25 — 会话内搜索结果

打开会话内搜索，输入关键词，搜索完成后显示无匹配结果。

### CH26 — Summary 面板

打开详情 header Summary 入口，右侧聊天内 Summary 面板打开。

### CH28 — 会话内搜索结果定位

打开会话内搜索，输入可命中消息的关键词，点击搜索结果的「定位到聊天」操作。

## CH28 预期结果

- 搜索结果展示命中消息及独立的「定位到聊天」操作。
- 点击后搜索面板保持打开，定位操作可再次观察到。

## CH28 反例

- 点击消息正文代替定位操作，或定位按钮不可见。
- 点击后搜索面板异常关闭，或定位操作不可继续观察。

### CH32 — 创建子区完成

从群会话的子区面板打开「新建子区」，填写名称并提交；子区列表显示新建的子区名称。

### CH34 — 发起群聊完成

从 Chat 顶部添加菜单打开「发起群聊」，填写群名并选择成员提交；创建弹窗关闭并进入新群会话。

### CH32 — 创建子区完成

从群会话的子区面板打开「新建子区」，填写名称并提交；子区列表显示新建的子区名称。

## UI assertions

只断言用户可见的 dialog、面板、标题和空结果状态；不断言请求 body 或埋点。
